# Rohit Sharma | Developer Portfolio

Personal portfolio website of an aspiring full-stack developer, built with plain HTML, CSS and JavaScript.

**Live site:** coming soon (the link will be added here after deployment)

## What's on the site

- Hero section with photo, role and a download button for my resume
- About me
- Skills: frontend, backend and APIs, databases, CS fundamentals, tools
- Projects: NewsFlash (React news app), Backend API practice (FastAPI), Python logic and DSA practice
- Education
- Contact links

## Folder structure

```
.
├── index.html                 # Page structure and all content
├── style.css                  # Dark developer theme and responsive layout
├── script.js                  # Small script that updates the footer year
├── photo.jpg                  # Profile photo used in the hero section
├── Rohit_Sharma_Resume.pdf    # File for the "Download resume" button
└── README.md                  # This file
```

## Built with

- HTML5
- CSS3 (variables, grid, flexbox, responsive design)
- JavaScript (vanilla)
- Google Fonts: IBM Plex Sans and JetBrains Mono

## Run it locally

No installation is needed.

```
git clone https://github.com/rs3971269-coder/Portfolio-.git
cd Portfolio-
```

Then open `index.html` in your browser.

## Customize

- Change text and project links in `index.html`
- Change colors in the `:root` block at the top of `style.css`
- Replace `photo.jpg` or `Rohit_Sharma_Resume.pdf` with new files using the same names
